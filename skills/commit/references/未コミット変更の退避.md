# 未コミット変更の退避

mainの未コミット変更が統合・同期を妨げる場合だけ読む。

対象パスを示し、退避して統合するか、統合せず停止するかを、利用可能な質問手段で確認する。退避には明示的な承認が必要であり、回答前にstashしない。

承認されたら次の順に進める。

1. main側で今回の退避と分かる日本語メッセージを付けて `git stash push -u` を行う。作成されたstashの識別子を記録する。
2. 呼び出し元の統合・push・同期確認を行う。
3. 今回作成したstashを指定して `git stash pop` し、復元結果を確認する。他のstashには触れない。

途中で失敗した場合も、退避状態を確認して安全に戻せるなら復元する。復元が競合した場合はstashを残し、競合パスとstashの識別子を報告する。`drop`・`clear` は行わない。

統合せず停止する回答なら、変更を保持し、コミットSHAと未完了の操作を報告する。
